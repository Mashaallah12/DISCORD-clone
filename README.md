# DISCORD-CLONE
The **Discord Clone** is a web application built to replicate the basic features of the popular Discord platform, focusing on real-time communication, user interactions, and a user-friendly interface. The project uses technologies like **HTML**, **CSS**, and **JavaScript** to create a responsive, interactive environment for chatting, creating servers, and joining channels.

**Key Features:**
1. **User Interface**: A sleek, user-friendly design mimicking Discord’s layout, including sidebars, server/channel lists, and chat windows.
2. **HTML/CSS**: Used for structuring and styling the page, ensuring it is responsive across various devices and maintains the aesthetic of Discord's interface.
3. **JavaScript**: Implements interactive features like joining channels, typing in chat boxes, and possibly adding more dynamic elements such as live notifications.
4. **Basic Authentication**: Simple login and registration forms for users to create accounts and access their chats.

This project allows for hands-on practice with front-end technologies while building a functional and visually appealing clone of Discord's core features, focusing on communication and real-time interaction.
